# Cloud ERP 进销存系统

跑在 **Cloudflare Workers + D1** 上的现代化无服务器（Serverless）进销存 ERP 系统，个人 / 小微企业 / 店铺免费使用（Cloudflare 免费额度完全覆盖）。

- **后端**：Hono + D1（SQLite），单 Worker 同时承载 API、静态页面托管与 Cron 定时任务
- **前端**：Vue 3 原生单页应用（免构建步骤），响应式暗黑科技感 UI，适配桌面与手机端
- **安全**：多用户角色权限体系（管理员 / 员工 / 销售），SHA-256 哈希安全存储，HMAC 签名 Session Cookie
- **数据**：支持本地全量 JSON 备份与还原、WebDAV 远程定时自动备份（坚果云 / 群晖 / AList 等）

## 成本核算机制

系统采用 **移动加权平均法** 进行成本与毛利核算：
- 每次采购入库时，自动根据 `(原库存×原均价 + 新入库量×新进价) / 总库存` 重算该商品的移动加权成本。
- 销售出库时，即时对当时成本均价进行**快照固化**，确保历史订单的毛利不受日后进价波动影响。
- 支持在商品管理中手动指定并**锁定成本均价**，锁定后不随采购流水变动。
- 任何历史单据修改或删除后，系统会自动全量重放重算，确保账实严格相符。

## 部署到 Cloudflare（全新干净部署）

部署后默认是一个**全新的空进销存系统**，包含管理员默认账号（`admin` / `admin123`），不包含任何业务数据：

1. 登录 Cloudflare 并创建 D1 数据库：

   ```sh
   npx wrangler login
   npx wrangler d1 create cf-erp
   ```

2. 将上一步输出的 `database_id` 填入项目根目录下的 `wrangler.jsonc`。

3. 部署到 Cloudflare Workers：

   ```sh
   npm run deploy
   ```

4. 访问你的 Workers 域名（建议在 Cloudflare 后台绑定自定义域名），输入默认账号 `admin`，密码 `admin123` 即可登录。

5. 登录后进入「系统设置」：
   - 可以在「公司与系统配置」中修改店铺名称、电话、地址。
   - 可以在「用户账号管理」中修改默认密码或添加员工账号。
   - 可以在「数据备份与恢复」中上传历史备份文件一键还原数据。

## 本地开发

```sh
npm install
npm run dev        # 启动本地服务：http://127.0.0.1:8787
```

运行自动化集成测试：

```sh
node test/api.test.mjs
```

## 目录结构

```
cf-erp/
├── wrangler.jsonc        # Cloudflare Worker 配置（D1 绑定、静态资源、Cron 触发器）
├── src/
│   ├── index.ts          # 入口路由与定时触发器
│   ├── auth.ts           # 多用户认证与权限验证中间件
│   ├── users.ts          # 用户管理与权限分配 API
│   ├── db.ts             # 数据库初始化、列迁移与流水重算引擎
│   ├── schema.sql        # 初始数据表结构定义
│   ├── products.ts       # 商品与库存流水模块
│   ├── purchases.ts      # 采购入库与退货模块
│   ├── sales.ts          # 销售出库与退货模块
│   ├── accounts.ts       # 结算账户与资金流水模块
│   ├── parties.ts        # 往来单位（客户/供应商）模块
│   ├── reports.ts        # 毛利/汇总/欠款/其他收支报表
│   ├── backup.ts         # 本地全量 JSON 备份与还原
│   └── webdav.ts         # WebDAV 远程自动定时备份
├── public/               # 前端单页应用
│   ├── index.html        # UI 模板与打印模板
│   ├── app.js            # Vue 3 业务逻辑与选择器组件
│   └── style.css         # 科技感现代化主题样式
└── tools/                # 历史数据迁移与调试脚本
```
